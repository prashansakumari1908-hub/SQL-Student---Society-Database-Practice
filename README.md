# SQL Student-Society Database Practice

This repository contains my SQL practice work based on a Student-Society database schema.

## Topics Covered

- SELECT and WHERE
- JOINs
- Aggregate Functions
- GROUP BY and HAVING
- Subqueries
- CASE Statements
- UPDATE and ALTER TABLE
- Foreign Keys
- Date and Age Calculations
- COUNT, MAX, MIN and other SQL functions
- Basic Database Administration

## Database

DBMS: PostgreSQL

The practice includes 30 SQL problems designed to strengthen database querying and problem-solving skills.

## What I Learned

While solving these problems, I also practiced debugging SQL errors and adapting queries according to PostgreSQL syntax instead of simply memorizing solutions.

This project is part of my ongoing journey toward becoming a Data Analyst.
